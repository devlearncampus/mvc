[ MVC ] - 규모가 클때(엔터프라아즈 급)
  1.정의  - Model, View, Controller를 의미 
               
  2.의미 - 개발 방법론을 의미 
             개발패턴(pattern) 이라고도 함
               
  3.mvc 을 적용해야 하는 이유 
     - 애플리케이션 개발 시 디자인(View-사용자에게 보여지는 영역)과 로직(업무를 반영한 모델)은 분리시켜야 
       유지보수성이 높아짐 (효율성과 비용 문제와 관련되므로..)
    
Model  -  로직
View - 디자인
Controller - 디자인과 로직을 분리시켜주는 영역 
---------------------------------------------------------------------
javaEE 분야는 대규모의 기업용 애플리케이션을 개발하는 플랫폼이므로, MVC를 준수하여 개발을 함..
이때 javaEE 기술로 디자인과 로직을 분리시켜 개발하는 방법을 가리켜 model2 라 부른다..

Model  -  순수  java 로 구현
View   -  jsp 로 구현
Controller  - 서블릿(서버측에서 실행될 수 있는 java 클래스)
---------------------------------------------------------------------

  로직(특히 db관련 ex) DAO, FileManager )을 별도의 클래스로 분리시켜 개발하는 방식
